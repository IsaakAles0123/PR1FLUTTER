# ПР1 — Макеты Flutter

Практическая работа №1 по МДК.01.03: реализация 4 макетов из Figma
(2 простых + 2 сложных) на оценку 5.

## Макеты

Страница 1 (простые):
- **medinow** — экран входа
- **Mind Deep Relax** — список сессий

Страница 2 (сложные):
- **Meditate** — каталог медитаций
- **Secrets of Atlantis** — карточка подкаста

## Запуск

```bash
flutter pub get
flutter run
```

На главном экране две вкладки: «Простые макеты» и «Сложные макеты».
Нажмите карточку, чтобы открыть экран.
